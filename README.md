# API-agent

## Available agents

### API Testing Agent

A reusable agent specification for end-to-end API testing is available at:

- `agents/api-testing-agent/README.md`
- `agents/api-testing-agent/agent-prompt.md`
- `agents/api-testing-agent/coverage-matrix-template.md`

It is designed to provide broad coverage for any API, including:

- Functional and contract testing
- Negative and edge-case testing
- Authorization and security checks
- Reliability and lightweight performance checks
